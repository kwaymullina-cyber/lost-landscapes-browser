# The Lost Landscapes - Browser Edition

A self-contained HTML remake prototype of the island-building singing monster game.

## Play

Open `index.html` in a browser.

## Features

- Buy and place singing monsters on the island grid.
- Each monster adds a different Web Audio loop layer.
- Tap placed monsters to collect coins.
- Tempo, mute, reset, offline earnings, level, food, and coins.
- Progress saves automatically in `localStorage`.
- Infinite coins for sandbox play.
- Feed and remove tools for placed monsters.
- Optional owned/licensed WAV files in `assets/sounds` replace the generated synth sounds.
- In-game sound importer for local audio files matched by monster name.
- Air Island sounds from `/Users/braizo/Downloads/Air Island` are copied into `assets/sounds/air-island`, with one shop monster generated per WAV file.
- Sprite sheets downloaded from the Google Drive folder are stored in `assets/sprites/drive-download` and assigned to generated monsters.
