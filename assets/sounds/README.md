# Sound Files

Drop owned or licensed monster audio here to replace the generated synth sounds.

Expected filenames:

- `drumbler.wav`
- `reedle.wav`
- `glowbe.wav`
- `murmoss.wav`
- `shelltone.wav`

Short one-shot or loop-like WAV files work best. If a file is missing or cannot load, the game falls back to its built-in Web Audio synth voice for that monster.

You can also use the in-game `Import Sounds` button to pick audio files from your computer. Imported sounds are matched when the filename contains the monster id or name, such as `drumbler.wav` or `reedle_loop.ogg`.
